Watch Order

Watch films and episodes from across a franchise in one defined order. Each user's progress follows their normal watched status.

Settings
Needs the File Transformation plugin. Users may need to refresh the page after this changes.
With the library bar, it also appears in the side menu, and as an icon on screens too narrow for the library bar.
"After your libraries" puts it before the More button when some libraries don't fit.
Each user sees the orders they've started, with what's up next. They can add or remove orders from it themselves.
When something in an order a user is following starts, the order's next item is queued after it, so autoplay and "Up Next" play that instead of the usual next episode. Users change it on their Watch Orders page. Works in the web app and apps built on it; other apps are left alone.
Each user gets a playlist of what they have left in each order they're following ("Watch Order: …"), kept up to date as they watch, so they can carry on an order from any Jellyfin app. It goes when they finish, and comes back for a new watch-through. Users change it per order on its page; deleting the playlist turns it off for that order. Turning this off for everyone removes the playlists.
